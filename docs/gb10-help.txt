=== nemoclaw --help

  NemoClaw  v0.0.137-1-g95d0ed2472
  Deploy more secure, always-on AI assistants with a single command.
  Global commands run without a sandbox-name prefix; sandbox commands start with a sandbox name.
  Use `nemoclaw status` for the global overview, and `nemoclaw <name> status` for one sandbox.

  Getting Started:
    nemoclaw onboard                      Configure inference endpoint and credentials (--agent to choose runtime)
    nemoclaw onboard --from               Use a custom Dockerfile for the sandbox image
    nemoclaw agents list                  List available agent runtimes for onboard --agent
    nemoclaw profiles list                List installed serving profiles and evaluate host compatibility [--json]
    nemoclaw completion                   Generate shell completion script [bash|zsh|fish]

  Sandbox Management:
    nemoclaw list                         List all sandboxes [--json]
    nemoclaw use <name>                   Set the default sandbox [--json]
    nemoclaw launch <name>                Connect to a sandbox and start its agent
    nemoclaw <name> connect               Shell into a running sandbox [--probe-only]
    nemoclaw <name> dashboard-url         Print the dashboard URL (not supported for the experimental Hermes portable profile) [--quiet|-q]
    nemoclaw <name> recover               Repair a stopped sandbox gateway and host forwards
    nemoclaw <name> stop                  Stop the sandbox container, preserving workspace state
    nemoclaw <name> start                 Restart a stopped sandbox container
    nemoclaw <name> status                Show one sandbox's health and runtime status
    nemoclaw <name> exec                  Run a command non-interactively in a running sandbox [--workdir <dir>] [--tty|--no-tty] [--timeout <s>] -- <cmd> [args...]
    nemoclaw <name> agent                 Run one agent turn non-interactively in a sandbox [openclaw-agent-flags...]
    nemoclaw <name> download              Download a file or directory from the sandbox to the host <sandbox-path> [host-dest]
    nemoclaw <name> upload                Upload a file or directory from the host into the sandbox <host-path> [sandbox-dest]
    nemoclaw <name> doctor                Diagnose sandbox and gateway health [--json] [--fix]
    nemoclaw <name> logs                  Stream sandbox logs [--follow] [--tail <lines>|-n <lines>] [--since <duration>]
    nemoclaw <name> share mount           Mount sandbox filesystem on the host [sandbox-path] [local-mount-point]
    nemoclaw <name> share unmount         Unmount a shared sandbox filesystem [local-mount-point]
    nemoclaw config export <sandbox>      Export a sandbox to a NemoClaw configuration file --output <path|-> [--name <name>] [--force] [--json]
    nemoclaw <name> share status          Show sandbox share mount status [local-mount-point]
    nemoclaw <name> rebuild               Upgrade sandbox to current agent version [--yes|-y|--force] [--verbose|-v] [--observability|--no-observability]
    nemoclaw <name> gateway-token         Print the sandbox agent's auth token to stdout [--quiet|-q]
    nemoclaw <name> gateway restart       Restart the sandbox agent gateway [--quiet|-q]
    nemoclaw <name> destroy               Stop NIM and delete sandbox [--yes|-y|--force] [--cleanup-gateway|--no-cleanup-gateway] [--keep-vllm]
    nemoclaw <name> agents list           List OpenClaw agents configured in a sandbox [openclaw-agents-list-flags...]
    nemoclaw <name> agents add            Add an OpenClaw agent inside a sandbox [openclaw-agents-add-flags...]
    nemoclaw <name> agents delete         Delete an OpenClaw agent inside a sandbox <agent-id> [openclaw-agents-delete-flags...]
    nemoclaw <name> agents apply          Reconcile a sandbox's OpenClaw agents against a declarative manifest -f <agents.yaml> [--yes] [--non-interactive]
    nemoclaw <name> sessions              List conversation sessions in a sandbox [sessions-flags...]
    nemoclaw <name> sessions list         List conversation sessions in a sandbox [sessions-list-flags...]
    nemoclaw <name> sessions reset        Reset an OpenClaw conversation session via the gateway <key> [--agent <id>] [--reason new|reset] [--json] [--verbose]
    nemoclaw <name> sessions delete       Delete a conversation session from the sandbox <key> [--agent <id>] [--keep-transcript] [--json] [--verbose]
    nemoclaw <name> sessions export       Export agent session JSONL out of a running sandbox [keys...] [--agent <id>] [--format <dir|tar>] [--out <path>] [--include-trajectory] [--json]

  Skills:
    nemoclaw <name> skill install         Deploy a skill directory to the sandbox <path>
    nemoclaw <name> skill remove          Remove a named skill through the selected agent integration <skill>
    nemoclaw <name> skill list            List skills from the agent's native state

  Policy Presets:
    nemoclaw <name> policy get            Export the sandbox base policy with literal credentials redacted [--raw]
    nemoclaw <name> policy add            Add a network or filesystem policy preset (--yes, -y, --dry-run, --from-file <path>, --from-dir <path>, --trusted-private-host <host>)
    nemoclaw <name> policy remove         Remove an applied policy preset (--yes, -y, --dry-run)
    nemoclaw <name> policy list           List policy presets
    nemoclaw <name> hosts-add             Add a sandbox /etc/hosts alias <hostname> <ip> [--dry-run]
    nemoclaw <name> hosts-list            List sandbox host aliases
    nemoclaw <name> hosts-remove          Remove a sandbox /etc/hosts alias (--dry-run)
    nemoclaw <name> policy explain        Explain the active policy context for the sandbox (--json, --write)
    nemoclaw <name> policy exclude <key>  Exclude an entry from the agent baseline policy (--force, --yes, -y, --dry-run)
    nemoclaw <name> policy restore <key>  Restore a previously excluded baseline entry (--force, --yes, -y, --dry-run)

  Messaging Channels:
    nemoclaw <name> channels list         List supported messaging channels
    nemoclaw <name> channels add <channel> Save messaging channel credentials and rebuild [--dry-run]
    nemoclaw <name> channels remove <channel> Clear messaging channel credentials and rebuild [--dry-run]
    nemoclaw <name> channels stop <channel> Disable channel without wiping credentials [--dry-run]
    nemoclaw <name> channels start <channel> Re-enable a stopped messaging channel [--dry-run]
    nemoclaw <name> channels status       Inspect messaging channel status [--channel <channel>] [--wait] [--timeout <seconds>] [--json]

  MCP Servers:
    nemoclaw <name> mcp list              List configured MCP servers [--json]
    nemoclaw <name> mcp add               Add an OpenShell-enforced MCP HTTP server <server> --url <url> --env KEY [--deny-tool TOOL ...]
    nemoclaw <name> mcp update            Replace or clear MCP denied-tool rules <server> (--deny-tool TOOL [...] | --clear-deny-tools)
    nemoclaw <name> mcp status            Inspect MCP server health and advertised tools [server] [--json] [--probe|--no-probe] [--tools]
    nemoclaw <name> mcp restart           Refresh one or all MCP server registrations [server]
    nemoclaw <name> mcp remove            Remove an agent registration and detach its provider <server> [--force]
    nemoclaw <name> mcp migrate           Preview or apply legacy-to-native MCP migration [--apply] [--json]

  Compatibility Commands:
    nemoclaw setup                        Deprecated alias for onboard
    nemoclaw setup-spark                  Deprecated alias for onboard

  Services:
    nemoclaw tunnel start                 Start the cloudflared public-URL tunnel
    nemoclaw tunnel stop                  Stop the cloudflared public-URL tunnel
    nemoclaw tunnel status                Show cloudflared public-URL tunnel status
    nemoclaw start                        Deprecated command that prints start migration guidance
    nemoclaw stop                         Deprecated full stop (also releases the managed gateway port)
    nemoclaw inference get                Show the selected NemoClaw inference path [--json]
    nemoclaw status                       Show global sandbox and host service status [--json]
    nemoclaw inference set                Switch the NemoClaw inference model --provider <provider> --model <model> [--sandbox <name>] [--no-verify]

  Troubleshooting:
    nemoclaw doctor                       Diagnose host and gateway health [--json|--text]
    nemoclaw debug                        Collect diagnostics for bug reports [--quick] [--output FILE|-o FILE] [--sandbox NAME]
    nemoclaw host probe                   Report host and gateway readiness without changing the system [--json]

  Credentials:
    nemoclaw credentials add              Register a provider credential <PROVIDER> --type <TYPE> [--credential ENV_NAME] [--config K=V] [--from-existing]
    nemoclaw credentials list             List stored credential providers
    nemoclaw credentials reset            Remove a provider credential <PROVIDER> [--yes|-y]

  Backup:
    nemoclaw backup-all                   Back up all sandbox state before upgrade

  Upgrade:
    nemoclaw update                       Run the maintained NemoClaw installer update flow (--check, --fresh, --allow-downgrade, --yes|-y)
    nemoclaw upgrade-sandboxes            Detect and rebuild stale sandboxes (--check, --auto, --yes|-y)

  Resources:
    nemoclaw resources                    Show hardware inventory (CPU cores, RAM, GPU VRAM) [--json]

  Cleanup:
    nemoclaw gc                           Remove orphaned sandbox Docker images (--yes|-y|--force, --dry-run)
    nemoclaw uninstall                    Run uninstall.sh

  Uninstall flags:
    --yes                             Skip the confirmation prompt
    --keep-openshell                  Leave the OpenShell binary installed
    --delete-models                   Remove all Ollama models and non-credential Hugging Face cache data (authentication files remain)
    --destroy-user-data               Skip eligible fresh backups; remove preserved user data; remove managed CLI shims only when no sibling gateway is confirmed
    --all-gateway-ports               Uninstall every gateway port on this host, not only NEMOCLAW_GATEWAY_PORT

  Reconfiguration (after onboard):
    • Check inference route:   nemoclaw inference get
    • Change inference model:  nemoclaw inference set --model <model> --provider <provider>
    • Add network presets:     use the policy add command on your sandbox
    • Change credentials:      credentials reset <PROVIDER>, then re-run onboard
    • Agent config is writable in the default sandbox so OpenClaw can manage runtime state.
      Use host-side commands or re-run onboard for durable OpenClaw settings.

Options:

                             last|telegram|whatsapp|discord|irc|googlechat|slack|signal|imessage|feishu|nostr|buzz|msteams|mattermost|nextcloud-talk|matrix|raft|a2a|line|zalo|clickclack|zalouser|sms|synology-chat|tlon|qa-channel|reef|twitch

  --deliver                  Send the agent's reply back to the selected channel
                             (default: false)
  -h, --help                 Display help for command
  --json                     Output result as JSON (default: false)
  --local                    Run the embedded agent locally using configured
                             provider credentials or local CLI logins (default:
                             false)
  -m, --message <text>       Message body for the agent
  --message-file <path>      Read the agent message body from a UTF-8 file (max
                             4 MiB)
  --model <id>               Model override for this run (provider/model or
                             model id)
  --reply-account <id>       Delivery account id override

  --reply-to <target>        Delivery target override (separate from session
                             routing)
  --session-id <id>          Use an explicit session id

                             session key
  --thinking <level>         Thinking level: off | minimal | low | medium | high
                             | xhigh | adaptive | max | ultra where supported
  --timeout <seconds>        Override agent command timeout (seconds, default
                             600 or config value)
  --verbose <on|off>         Persist agent verbose level for the session
